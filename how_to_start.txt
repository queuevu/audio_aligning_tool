./run.sh

That's it. On first run this creates .venv and installs everything
(PySide6, aeneas, numpy) automatically — no manual venv setup needed,
even on a fresh clone. Subsequent runs reuse the existing .venv.

Requires espeak/espeak-ng and ffmpeg installed system-wide (macOS: brew
install espeak-ng ffmpeg) and python3.10 available on PATH (aeneas needs
3.10; brew install python@3.10 if missing).

This opens the desktop app window where you:

Browse/drag-drop a .wav file
Pick the language (English/Kannada/Tamil)
Paste the transcript (blank line between parts/prayers)
Choose an output .json path
Click Generate Alignment

To run the Bible Batch Alignment Tool instead:

./run.sh bible_main.py

To re-run setup manually (e.g. after changing requirements.txt):

./setup.sh
